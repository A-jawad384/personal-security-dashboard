# Personal Security Monitoring Dashboard

A defensive cybersecurity project designed to collect, analyze, and visualize security events.

## Project Objectives

- Collect security events and logs
- Store security events
- Detect suspicious activity
- Display security statistics
- Generate alerts
- Support basic security investigation
- Generate security reports

## Planned Technologies

- Flask
- HTML
- CSS
- JavaScript
- Bootstrap
